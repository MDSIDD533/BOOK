## 🌟 Features

1. **📖 1-Click Story ➡️ Full HD Animated Video + Voice (`Story to Video`)**:
   - Paste any story in **Roman Urdu**, **اردو (Urdu Script)**, **English**, or **हिंदी (Hindi)**.
   - Automatically splits your story word-for-word into dramatic scenes, animates storybook characters & worlds (Lion, Clever Rabbit, Forest Council, Deep Stone Well & Reflection, Village, Mountains, Storms, Palaces & Skies) at **24 FPS HD (`720x1280`, `1280x720`, `960x960`)**.
   - Adds synchronized **Karaoke Word-Highlight Subtitles** + automatic **Polyphonic Cinema Background Music**.
2. **🎙️ 28 Lifelike Neural Voices (`Kokoro-82M` Offline Studio Engine)**:
   - Works out-of-the-box with **zero API keys required**.
   - Custom **Roman-Urdu Phonetic Transliteration Engine** for natural South Asian storytelling intonation, plus Dual-Voice Mixing & Studio Mic EQ.

## 🚀 Run Locally

```bash
git clone https://github.com/MDSIDD533/BOOK.git
cd BOOK
npm install --ignore-scripts
pip install onnxruntime kokoro-onnx numpy scipy
npm run dev
```

Open **`http://localhost:3000`** in your browser!
